Cybersecurity Landscape Problem Statement

Problem Statement & Industry Context

Why traditional signature-based intrusion detection fails against modern polymorphic attacks

Deficiencies of Legacy IDS (Snort / Bro)
  • Zero-Day Vulnerability: Rigid static signatures fail when byte patterns or hashing signatures change.
  • Severe Alert Fatigue: High false-positive rates (>4,000 noise alerts/day) overwhelm security analysts.
  • Fragmented Workflows: Disconnected CLI tools and raw PCAP dump files delay incident response.
  • Resource Exhaustion: High memory consumption when maintaining millions of static rule chains.
The NetSentinel AI Solution
  • Behavioral ML Detection: Evaluates flow statistical connection dynamics rather than static strings.
  • Sub-2ms Multi-Class Scoring: Instantly categorizes DoS, Probe, R2L, U2R, and Brute Force flows.
  • Automated Alert Triage: Immediate incident creation with severity tagging and resolution lifecycle.
  • Continuous Adaptation: Asynchronous retraining engine incorporates verified production logs.
Key Industry Metric
Cybersecurity research indicates that over 80% of successful breaches exploit polymorphic techniques or novel zero-days that bypass signature databases. NetSentinel AI tackles this by operating on statistical connection dynamics across 41 dimensions.

Architectural Resilience Highlight
Heavy ML model retraining runs in a decoupled daemon thread, completely preventing HTTP worker starvation. Socket capture errors seamlessly trigger the synthetic generator fallback so web telemetry remains uninterrupted.

Algorithmic Foundation Machine Learning Pipeline

41-Dimensional Feature Engineering & ML Model

NSL-KDD benchmark standards mapped to an optimized Random Forest ensemble classifier

Basic Features (1–9)
Protocol, service, status flags (SF, S0, REJ), duration, source bytes, and destination bytes.
Content Features (10–22)
Payload flags: num_failed_logins, logged_in, root_shell, su_attempted, is_guest_login.
Time Traffic (23–31)
2-second window metrics: connection counts, serror_rate (SYN error rate), and same_srv_rate.
Host Traffic (32–41)
100-connection target metrics: dst_host_count, dst_host_srv_count, and service error ratios.
Why Random Forest Ensemble?
  • Superior Tabular Performance: Outperforms deep neural networks on structured heterogeneous network attributes.
  • Resistance to Overfitting: Bagging and random feature sub-sampling prevent trees from memorizing noise.
  • Inherent Explainability: Computes exact Gini feature importance scores displayed directly to the security analyst.
  • Low Computational Footprint: Evaluates flows in <2ms without requiring expensive GPU accelerators.
Top Contributing Decision Features
  • dst_host_srv_count (Relative Weight: 0.14) — Host service density
  • src_bytes (Relative Weight: 0.12) — Payload outbound volume
  • dst_bytes (Relative Weight: 0.11) — Return payload verification
  • serror_rate (Relative Weight: 0.10) — Incomplete TCP handshakes
  • same_srv_rate (Relative Weight: 0.09) — Protocol uniformity

Analyst Triage & Resolution Loop
Whenever a flow breaches threat thresholds, an Alert is created with an is_resolved=False state. Analysts examine the telemetry (Source IP, Port, Confidence) and mark it resolved via POST /alerts/<pk>/resolve/, maintaining a clean audit trail.

Data Persistence Database Schema & ERD

Database Architecture & Data Dictionary

15-table relational catalog implemented in SQLite with Django ORM referential integrity

ids_alert
High-priority security alerts generated during live or batch scoring.
  • attack_type (varchar 50)
  • severity (low..critical)
  • confidence (0.0..100.0)
  • is_resolved (boolean)
  • FK to auth_user (SET_NULL)
ids_trafficlog
Granular connection flows for audit and continuous model retraining.
  • source_ip, dest_ip
  • protocol (TCP/UDP/ICMP)
  • duration, src_bytes
  • prediction & confidence
  • FK to auth_user (SET_NULL)
ids_predictionrun
Batch CSV scoring jobs with embedded JSON telemetry summaries.
  • input_filename (varchar)
  • total_records (positive int)
  • overall_class (malicious/normal)
  • feature_importance (JSON)
  • FK to auth_user (CASCADE)
ids_modelmetrics (Time-Series)
Stores statistical benchmarks after each initial or background retraining cycle: accuracy, precision, recall, f1_score, and samples_trained.
ids_userprofile (RBAC Isolation)
1-to-1 extension of Django's auth_user table containing the operational system role ('user' or 'admin') powering multi-tenant workspace isolation.
